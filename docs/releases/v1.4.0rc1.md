# SAP v1.4.0rc1 — first public desktop preview

SONAR Analysis Program (SAP) is a research application from SUSTech-BIO 2026 iGEM Team for Reporter sequence design, flow-cytometry analysis and reference-data inspection. This is a **pre-release**, not a signed stable release.

## Download and start

- **Windows x64:** download `SAP-1.4.0rc1-windows-x64-portable.zip`, fully extract it, then open `SAP/SAP.exe`. Keep the entire folder together, including `_internal`. The package includes Python and a fixed Microsoft WebView2 Runtime.
- **macOS Apple Silicon:** download `SAP-1.4.0rc1-macos-arm64.dmg`, open it and drag `SAP.app` to Applications. Intel Macs are not supported by this artifact. The configured deployment floor is macOS 14; the local verification host was macOS 26.5.2.
- No separate Python installation or terminal commands are required. Installation instructions are included in each package and linked in the repository.

## Included features

- Sequence design and visual editing-site selection, oligo output, Reporter construct downloads and maps.
- An experiment workflow: initialization → control upload → Theta preview → sample upload → results.
- Mock-derived calibration, RAS computation, reference-equivalent RES model estimates and report export.
- Input-stage examples and all 883 manifest-verified scientific reference files.
- Local experiment storage, native file dialogs and a dedicated desktop window.

## Verification and scope

The Windows build runs application and sequence tests, then checks the frozen executable using real bundled FCS data and a native GUI self-test. The macOS build checks the same frozen FCS workflow and native GUI. Per-platform build manifests and checksums accompany this release. Earlier manual macOS checks also covered upload dialogs, CSV/ZIP saving and restart recovery.

RES is an AC DNA mass reference-equivalent quantity. A model estimate must not be interpreted as a validated cross-batch transfer or a direct RNA editing percentage. The application's existing qualification and uncertainty labels remain in effect.

## Known limitations

- Windows is unsigned. macOS is ad-hoc signed, not Developer ID signed or notarized. Operating-system security may warn or block first launch. Do not disable system security or bypass malware warnings; this preview does not promise frictionless installation.
- Windows automated execution uses a Windows Server 2022 x64 runner. Manual acceptance on clean Windows 11 machines remains pending.
- No Intel Mac, Windows ARM64 or Linux desktop package is provided.
- The fixed WebView2 Runtime does not auto-update; security updates require a new SAP package.
- SAP's analysis and resources are local; no cloud computation is required. OS/browser-runtime diagnostics remain governed by their vendors' settings and terms.
