## SONAR Analysis Program

SONAR Analysis Program (SAP) provides a graphical workflow for Reporter sequence design, control-based calibration and flow-cytometry analysis. It reports RAS and reference-equivalent RES with their applicability and uncertainty labels. Example inputs, reference data and report export are included.

SAP v1.4.0rc1 is a public desktop preview. No separate Python installation is needed. The Windows package is unsigned; the Apple Silicon macOS package is not notarized, so first launch may be blocked by operating-system security. Intel Mac packages are not available in this release.
