7.3 Fit candidate calibration models
Evaluate a small, scientifically justified set of models.
Include, where appropriate:
Model A — Affine calibration
\[
RAS=\alpha+\beta A
\]
Model B — Monotonic shape-constrained calibration
A piecewise or isotonic response subject to explicit monotonicity assumptions.
Model C — Low-complexity nonlinear calibration
Use only if the data density and independent replication justify additional parameters.
Avoid high-degree polynomial interpolation or flexible models that simply pass through every measured point.
For each model:
- Fit using the independent well-level RAS observations.
- Estimate parameter uncertainty.
- Examine residuals.
- Evaluate local response resolution.
- Assess inversion stability.
- Compare prediction and reference-fraction recovery.
- Identify regions where different input fractions are not distinguishable.
Do not select a model solely because it produces a complete 0–100% inverse.

8. Phase V — Layer 3 PER Calibration
Objective
Use the molecular results from Phase III and optical results from Layers 0–2 to evaluate whether SONAR can predict an independently measured RNA-editing endpoint.
Do not assume that successful computation of a Sanger secondary-peak metric automatically qualifies the data for PER.

The first intended endpoint is:
Editing fraction at a named site of S10 OpenA reporter RNA.
Do not substitute introduced APOE or endogenous APOE editing measurements without appropriate target-specific evidence.
If C280 is independently confirmed as the target, use its verified sequence and coordinate definition.
Specify:
- Target transcript.
- Site and strand.
- Reference and alternative nucleotides.
- Sampling population.
- Measurement method.
- Uncertainty.
- Independent experimental unit.
The term PER refers to a predicted edited fraction at the sampling time, not a kinetic derivative.
8.2 Reconstruct the final flow–RNA pairing table
Use the existing:
results/flow_RNA_well_registry.csv

For every well, join:
- Reporter-population RAS.
- Co-expression RAS where available.
- BFP-positive fraction.
- Reporter/editor DNA inputs.
- Molecular result.
- Molecular result uncertainty.
- Molecular assay qualification status.
Preserve the distinction between measured RNA population and flow-selected population.
If RNA was extracted from bulk remaining cells rather than sorted \(R^+B^+\) cells, do not label the molecular result as a co-expression-gated editing fraction.
8.3 First evaluate the actual biological relationship
Before fitting a predictive model, examine the measured relationship between:
- Editor DNA loading.
- BFP-positive fraction.
- RAS.
- Molecular editing-associated signal or qualified RNA-editing fraction.
The previous S10 analysis showed that BFP-positive prevalence increases with editor DNA loading, while RAS does not increase monotonically.
Investigate whether the new molecular results show:
- A dose-associated editing signal.
- A relationship with reporter-population RAS.
- A relationship with co-expression RAS.
- A relationship with BFP expression.
- A discrepancy between fluorescence activation and the molecular endpoint.
Do not hide negative or unexpected associations.
A strong dose-dependent molecular editing signal combined with weak or nonmonotonic RAS would be an important scientific result, even if it limits the usefulness of PER.
8.4 Fit a direct RAS-to-RNA baseline
If qualified molecular editing fractions are available, first establish a simple baseline:
\[
E_{\mathrm{RNA}}=f(RAS)
\]
Evaluate a model appropriate for the small number of independent wells.
Avoid unnecessary complexity.
If only relative chromatogram signals are supported, analyze their relationship with RAS as an exploratory association, not as a PER model.
8.5 Fit the staged SONAR model
If a suitable RES calibration exists and can legitimately be transferred to the corresponding S10 reporter population, evaluate:
\[
E_{\mathrm{RNA}}=h(RES)
\]
and:
\[
PER=100h(RES)\%
\]
Do not apply an invalid or non-identifiable RES simply to complete the four-layer chain.
If a valid S7-to-S10 calibration bridge is unavailable, report that limitation and do not present an unsupported staged PER.
8.6 Compare direct and staged prediction
This comparison is scientifically important.
Compare:
\[
RAS\rightarrow E_{\mathrm{RNA}}
\]
against:
\[
RAS\rightarrow RES\rightarrow PER
\]
using the same appropriate independent held-out observations.
Where the data support meaningful evaluation, report:
- MAE.
- RMSE.
- Signed bias.
- Prediction intervals.
- Prediction-interval coverage, where estimable.
- Performance across the observed molecular-response range.
Use validation splits grouped by independent transfection well.
Keep all technical sequencing observations from the same well together.
Explore leave-one-dose-condition-out evaluation if feasible, while acknowledging the small sample size and the uncertainty of extrapolating to unseen doses.
Do not randomly divide events or sequencing reads from the same well into independent training and test sets.
Important mathematical consideration
If RES is a deterministic invertible transformation of RAS, it does not inherently introduce new sample-level information.
Any apparent improvement must therefore be interpreted carefully.
The intermediate reference calibration may improve standardization, interpretability, or model behavior, but predictive superiority is not guaranteed.
Do not claim that adding a calibration layer automatically improves RNA-editing prediction.
8.7 Evaluate alternative explanatory models
If the molecular endpoint is qualified but a simple RAS-only model performs poorly, consider a limited exploratory analysis incorporating:
- Reporter-population RAS.
- BFP-positive fraction.
- Co-expression RAS, where defined.
- Relevant expression covariates.
Such models must be named separately.
For example:
\[
E_{\mathrm{bulk}}
=
h(RAS,CEF,\text{expression covariates})
\]
Do not silently redefine the original RAS or RES to incorporate additional predictors.
Given the small number of independent S10 wells, prioritize model interpretability and conservative complexity.
Do not interpret editor-dose associations as proof of causal editing efficiency.
8.8 PER qualification rules
Only report a validated PER when:
1. The molecular editing site and endpoint are sufficiently established.
2. The molecular assay supports quantitative editing-fraction estimation.
3. Flow and RNA observations are correctly paired.
4. The relevant population and calibration domains are compatible.
5. Model performance has been appropriately evaluated on independent experimental observations.
6. The prediction uncertainty and supported input range are documented.
If these conditions are not met, complete the computational implementation and any scientifically useful exploratory fitting, but label it appropriately.
A provisional model must not be presented as a validated RNA-editing predictor.

13. Scientific Integrity and Decision Rules
The goal is to complete the strongest scientifically defensible SONAR system supported by the available data.
Actively attempt the calibration.
Do not stop at feasibility discussion when actual model fitting and evaluation can be performed.
Do not force successful calibration.
A fitted function is not automatically a validated measurement.
Preserve the existing numerical foundations.
Do not alter RAS definitions or Layer 0–1 parameters to improve RES/PER performance.
Use the original experimental evidence.
The provisional OpenA reconstruction is a lead to verify, not a ground-truth reference to assume.
Maintain independent experimental units.
Technical reads, repeated acquisitions, and flow events do not increase biological sample size.
Separate molecular signals from editing percentages.
An uncalibrated secondary-peak ratio must not be reported as a quantitatively verified RNA-editing fraction.
Separate reporter calibration from molecular calibration.
An AC DNA input fraction is not an RNA editing percentage.
Respect population compatibility.
Do not transfer reporter-population calibration to BFP-gated populations without evidence.
Report negative results.
If molecular editing increases while RAS remains weak or nonmonotonic, investigate and report that finding rather than forcing the expected relationship.
Use the available data efficiently.
Do not pursue unnecessarily complex models when independent sample size is limited.
Continue despite partial limitations.
If PER cannot be validated, deliver the completed molecular analysis, exploratory associations, supported Layer 2 results, reproducible software, and precise reasons preventing further claims.
