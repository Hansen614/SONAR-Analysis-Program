# SONAR 最终科学结论与交接

版本：sonar-science-v1.0-s7s10。原始 v4 ZIP、FCS、AB1 和 RAS 数值保持不变。主模型冻结为固定 50% 折点的单调分段线性模型；RES 表示 AC DNA 质量比例参考当量，不是 RNA 编辑率。

- 留一参考水平前向 RMSE 为 0.036368 RAS（16 个可作前向插值的留出孔）；逆推 19/20 成功，成功孔 MAE 6.153、RMSE 7.078 个百分点。5.848 个百分点仅属于三个模型都成功的 14 孔共同子集。
- 20 个 S7 孔均有研究用 RES，约 1.64–96.55% AC 质量当量。参考曲线的较好诊断区间仍为 RAS 0.7845–1.0065（主模型约54.52–80.41%当量），但不是验证过的定量范围。两孔位于该区间，加入样本测量不确定性后，两个模型联合区间宽度为20.8和21.8个百分点，均略超过20个百分点的严格标准。数字保留，状态明确。
- 窄的条件重采样区间在留一水平验证中仅覆盖5/20真值，因此同时提供更宽的模型误差兼容区间；后者也不是经过验证的95%置信区间。
- RAS 的中位孔间CV：S7从4.697%降至1.767%，S10从6.711%降至5.142%。改善的是本次实验的重复性；仍有红色表达水平依赖和光学限制。
- S10保留候选C280的相对测序信号；BFP比例与线性编辑器剂量的留一剂量预测误差接近。现有数据不能证明独立于剂量的BFP贡献。S7向S10转移未验证，绝对RNA编辑率和PER保持不可用。
